# NSU-CourseGrabber · 成都东软学院抢课脚本

针对成都东软学院教务系统（金智教务 `/xsxk`）的定时抢课脚本。填好配置，到点自动高频提交，抢上即停。

纯 Python 标准库实现，**零第三方依赖**（Python 3.9 即可运行，3.11+ 原生支持）。

## 免责声明

- 本脚本只做「定时 + 自动提交」，不绕过任何验证码、不破解任何限制。使用者需遵守学校选课相关规定，因使用本脚本产生的一切后果由使用者自行承担。
- 本脚本目前处于测试阶段，欢迎提交Issue反馈。
- 目前测试案例较少，可能会出现抢课失败的情况，所以还是建议动起大家的双手抢课～

## 快速开始

### 1. 环境准备

需要 Python 3.9 及以上。

Python 3.10 及以下需额外装一个 TOML 解析包（3.11+ 标准库自带，无需此步）：

```bash
pip3 install tomli
```

### 2. 获取配置信息

抢课前需要拿到三样东西：**token**、**batch\_id**、**课程号/课序号**。

#### 获取token

1. 用浏览器打开选课系统并**登录成功**
2. 按 `F12` 打开开发者工具 → 切到 **Console（控制台）**
3. 粘贴执行下面这行，复制输出的值：
   ```js
   sessionStorage.getItem('token')
   ```
4. 这串值就是 token，有效期通常是两个小时，建议在准备抢课前半小时获取，同时不要更换网络环境或浏览器，以免触发登录状态刷新。

#### 获取Batch\_id

进入选课页面后，看浏览器地址栏 URL，找到 `?batchId=` 后面那串字符，即为轮次 ID。

例如 `https://xk.dean.nsu.edu.cn/xsxk/grablessons?batchId=114aa514bb1919810cc66ccff `中，batch\_id 就是 `114aa514bb1919810cc66ccff`。

#### 获取课程号KCH与课序号KXH

进入选课页面的课程列表，每门课/每个教学班都带一个课程号（KCH）和课序号（KXH）。

- 体育项目课序号对应具体项目，例如 `019` = 跆拳道、`001` = 篮球，具体编号以选课页显示为准
- 也可以用浏览器 F12 抓 `/elective/clazz/list` 接口返回，里面的 `KCH`、`KXH` 字段即为目标值

### 3. 配置 config.toml

复制模板并编辑：

```bash
cp config.example.toml config.toml
```

打开 `config.toml`，填入你拿到的 token、batch\_id、课程号和抢课时间。课程名称无需填写，脚本会从服务器自动获取。

### 4. 运行

```bash
python3 grab.py
```

脚本会先校准服务器时间，然后显示倒计时，到点自动开抢，成功后打印并退出。

> 建议开抢前 5\~10 分钟启动。注意防止系统睡眠。

## 配置说明

| 字段                     | 所在段        | 示例值                               | 说明                                |
| ---------------------- | ---------- | --------------------------------- | --------------------------------- |
| `base_url`             | 顶部         | `https://xk.dean.nsu.edu.cn/xsxk` | 教务系统地址，一般不用改                      |
| `token`                | 顶部         | `38a7d1c9...`                     | **登录令牌**，每次登录后重新获取（见上文）           |
| `batch_id`             | 顶部         | `114aa514bb1919810cc66ccff...`    | 选课轮次 ID，来自选课页 URL 的 `?batchId=`   |
| `teaching_class_type`  | 顶部         | `TYKC`                            | 教学班类型。体育选课为 `TYKC`，其他类型见选课页目录菜单   |
| `campus`               | 顶部         | `1`                               | 校区代码，默认为1，即本校区                    |
| `KCH`                  | `[course]` | `1200000000`                      | 目标课程号                             |
| `KXH`                  | `[course]` | `001`                             | 目标课序号（体育项目对应具体项目），应当为3位数          |
| `grab_time`            | `[grab]`   | `2026-09-14 13:00:00`             | **开抢时间**，格式 `YYYY-MM-DD HH:MM:SS` |
| `pre_start_seconds`    | `[grab]`   | `5`                               | 提前多少秒开始试探提交（建议 3\~10）             |
| `retry_interval`       | `[grab]`   | `0.5`                             | 失败后重试间隔（秒），**请勿过小**以免触发风控         |
| `max_attempts`         | `[grab]`   | `1200`                            | 最大尝试次数，到上限自动退出                    |
| `secret_refresh_every` | `[grab]`   | `3`                               | 每 N 次尝试刷新一次课程 secretVal           |
| `end_time`             | `[grab]`   | `2026-09-14 13:10:00`             | 放弃时间，到点仍未抢到则退出                    |
| `request_timeout`      | `[grab]`   | `15`                              | 单次请求超时（秒）                         |

## 换课程 / 换轮次

- **换课程**：改 `[course]` 段里的 `KCH` 和 `KXH`
- **换轮次**：改顶部的 `batch_id` 和 `[grab]` 段的 `grab_time`
- **换类型**：非体育课时，把 `teaching_class_type` 换成对应菜单值（从选课页目录菜单查看）

修改后直接重新运行 `python3 grab.py`。

## 常见问题

| 现象                                               | 原因与处理                                        |
| ------------------------------------------------ | -------------------------------------------- |
| `无法获取服务器时间`                                      | token 失效或网络不通。重新登录获取新 token，更新 `config.toml` |
| `登录状态失效（401/402/403）`                            | token 过期，同上处理                                |
| 提交返回 `本轮次选课暂未开始`                                 | 正常，脚本在提前试探，时间一到服务器放行即成功                      |
| 提交返回 `code=301 确认选择课程吗`                          | 脚本已自动带 `isConfirm=1` 二次提交，无需人工干预             |
| `未在列表中匹配到教学班`                                    | KCH/KXH 配置有误，或该课程不在当前批次/校区，核对课程号和课序号         |
| `学生没有主修方案`                                       | 学籍侧限制，脚本无法绕过，需联系教务                           |
| 抢到了但想退课                                          | 登录选课系统在「已选课程」中手动退选即可                         |
| `ModuleNotFoundError: No module named 'tomllib'` | Python 版本低于 3.11，执行 `pip3 install tomli` 即可  |

## 注意事项

1. **合理频率**：默认 0.5 秒一次已是较高频率，请不要再调低 `retry_interval`，避免对教务服务器造成压力或触发风控。
2. **结果以系统为准**：脚本提交成功后会在「已选课程」列表中二次确认，但最终仍以教务系统显示为准，建议稍后登录核对。
3. **保持运行**：脚本需保持运行到抢课完成，开抢期间不要休眠电脑。
4. **token 安全**：`config.toml` 含账号凭证，**不要分享给他人**，也**不要提交到公开代码仓库**（本项目已通过 `.gitignore` 忽略该文件）。
